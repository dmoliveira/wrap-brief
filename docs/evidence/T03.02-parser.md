# T03.02 — hardened offline RSS/Atom adapters

Scope: pure byte-input metadata extraction with DTD/entity/external-reference denial, direct-child RSS/Atom structure, resource ceilings, deterministic output, per-item missing/invalid-title quarantine, hidden raw representations and bounded errors. No HTTP client, date/URL normalization, identity/grouping, backend, renderer or live source is implemented.

## Dependency/design review

Official defusedxml 0.7.1 source/API was checked before implementation. In particular, DTD denial defaults off upstream and is explicitly on here. The dependency has PSF licensing, no transitive requirements, and public PyPI artifacts. Exact-version `pip-audit` 2.9.0 on defusedxml 0.7.1, Ruff 0.16.2, UV/build 0.13.6 found no known vulnerabilities at review time. This is advisory evidence, not a guarantee of undisclosed security.

Native lock generation followed that audit. Lock review found only the local project, Ruff and defusedxml, with public PyPI/Python-hosted HTTPS URLs and SHA256 artifacts. Direct guarded dependency commands were not concealed or disabled. Locked execution and CI are the installation/validation paths.

## Executed local checks

- Full suite: **111 tests** passed on Python 3.11 and Python 3.13; lint, format and lock checks passed.
- Every shared fixture matches its exact metadata/quarantine/rejection expectation, including Latin-1, namespaces, updates, duplicate entries and unknown publication dates.
- DTD/entity/external probes (including UTF-16 and DTD without entities), malformed/unknown encoding, byte/depth/item/text/node budgets, nested fake entries, unsupported root/title types and network prohibition checks pass.
- A Python HTML-parser behavior difference was caught by testing: markup with no visible title is consistently quarantined rather than classified differently across Python versions.
- `make test-wheel`: isolated installed wheel imports the new parser and confirms the exact approved runtime dependency and empty live registry.

## Review and verification

- Critical implementation/security review found no critical/high/medium blocker; the upstream design, flags, metadata boundary, hard ceilings and lock were inspected.
- Independent verifier reran 111 tests on Python 3.11 and 3.13, full validation, isolated wheel installation, 52 standalone planning tests, workflow lint and whitespace checks: passed, no blockers.
- The real source registry remains empty. No HTTP client, normalizer, storage backend, renderer or scheduled process is introduced.

Publication-tree and committed-history Gitleaks scans found zero leaks. [PR #11](https://github.com/dmoliveira/wrap-brief/pull/11) / [clean CI run](https://github.com/dmoliveira/wrap-brief/actions/runs/41425768648) passed full validation, both supported Python versions, standalone planning and isolated-wheel checks. Final branch checks and merge state remain owned by GitHub. The future normalizer must validate raw URLs/dates/text before any persistence or rendering; this adapter is not a complete ingestion or SSRF boundary.
