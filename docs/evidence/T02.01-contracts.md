# T02.01 — core metadata contracts

Scope: standard-library immutable Source/Item/Cluster records, strict public config, deterministic versioned serialization, UTC/URL/provenance/reference checks, an empty live registry and synthetic compatibility tests. No fetching, XML parsing, grouping, persistence, renderer, provider setup or live publisher approval is implemented.

The prerequisite was explicitly refined under ADR 0001: T02.04 completed source investigation with a synthetic-prototype-only go; T02.02 remains blocked. The architecture/source boundary was reviewed before model implementation. This is not a permission bypass or a claim that private storage grants content rights.

## Executed checks

- `make validate`: passed, **84 tests** (30 model/config, 52 planning, two installed-package contracts), lock consistency, Ruff lint and formatting.
- Full suite on Python 3.11 and Python 3.13: passed independently. Standalone planning checks/subset still pass without importing the package.
- `make test-wheel`: passed; isolated wheel imports include the new core modules and confirm an empty default live registry.
- Version-1 compatibility fixture round trips all records and cross-record references without changing unknown dates or dropping fields.
- Negative cases cover malformed types/versions/JSON, duplicate keys/IDs, local/private URL literals, userinfo and credential query keys, false source attribution, unavailable/rumor/confirmation leads, invalid datetime ranges, source approval evidence, config size/encoding/symlink/I/O errors, and bounded/redacted error output.
- Review found incomplete Unicode-format handling and a caller-controlled error-label surface. Fixes reject the complete bidi-control set and Unicode line/paragraph separators while preserving emoji ZWJ, and make public URL errors use fixed internal labels. Metadata I/O errors are also redacted.
- Final scoped security/architecture sign-off: approved, no remaining blocker. Independent verifier reran both Python versions, full checks and wheel import: passed.
