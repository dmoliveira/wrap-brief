# T01.02 — reproducible Python foundation

## Scope

One `src`-layout package, Python 3.13 development default and Python 3.11 compatibility, zero runtime dependencies, exact UV build backend and locked Ruff development dependency. Local Make commands and the existing unprivileged required CI job share the locked environment. No source registry, feed collection, models, CLI, rendering, tracking, payments, or deployment is implemented.

The task reservation was expanded before implementation to include the README, existing CI integration, and this evidence record. One writer owns those shared paths.

## Verification plan

- Generate/check the lock using the CI-pinned UV 0.13.6 and public PyPI only.
- Locked sync and full validation; package import and no-runtime-dependency metadata checks.
- All tests on Python 3.11 and 3.13; standalone planning subset without the package.
- Controlled clean clone, locked setup and validation without production credentials.
- Build a wheel, install it in a separate environment, and import outside the checkout.
- Workflow lint, credential scans, reviewer and independent verifier.

Execution results and completion status are recorded only after these checks run. This evidence is not source-rights approval or a working news-site release.

## Dependency security review

The prior CI UV 0.9.7 pin failed advisory review (`PYSEC-2026-4321`, `GHSA-pjjw-68hj-v9mw`, `GHSA-4gg8-gxpx-9rph`; highest required fix version 0.13.4). This slice upgrades the CI pin to UV 0.13.6 and uses uv_build 0.13.6. Public PyPI metadata reports no transitive requirements for UV, uv_build, or Ruff. `pip-audit` 2.9.0 against exact UV 0.13.6, uv_build 0.13.6 and Ruff 0.16.2 found no known vulnerabilities at review time; that is not a guarantee against undisclosed vulnerabilities.

The local runtime blocks direct `uv sync` calls as a dependency-control policy. It is not disabled or bypassed: native `uv lock` follows the dependency review, and native `uv run --locked` validates without changing the lock. Explicit clean-runner `uv sync --locked` remains a required CI gate; no local sync success is claimed.
