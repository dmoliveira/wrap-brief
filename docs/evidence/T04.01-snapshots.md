# T04.01 — complete snapshots and local prototype adapter

Scope: immutable complete logical snapshots, typed checkpoint/tombstone data contracts, deterministic bounded JSON/checksums, pure replay merge and an owned-file local SQLite development adapter. No polling, retention expiry, migration, backup/provider, live durability, source activation or renderer is implemented.

Pre-code state-design review required local-adapter path reservation, explicit feed-window checkpoint fields, ownership/schema markers, consistent CAS/idempotence, canonical ordering and private-file boundaries. Those requirements were incorporated before validation. Pipeline orchestration changes remain T04.04, not this component.

Executed checks: **165 tests** on Python 3.11 and Python 3.13, lock/plan/link/generated-view checks, lint/format and strict ResourceWarning validation pass. Snapshot vectors include complete record/nullable-date round trips, canonical ordering, checkpoints/windows/unknowns, tombstones, unsafe schema/raw metadata rejection, replay/stale-source update and first-seen/publication preservation. Local tests cover CAS concurrency, idempotence, monotonic clear, interrupted rollback, cache loss, checksum/schema corruption, foreign DB protection, lost-file refusal, private paths and SQL-like text as data.

Review found a known-update/undated-observation rollback gap and an initialization permission window. Fixes preserve known source-update metadata, use observation only for tied/absent updates, require owner-only parent directories, and pre-create files exclusively as 0600 before SQLite opens them. Regression tests prove these cases and interrupted initialization. Scoped follow-up security review approved the code.

Independent verifier reran 165 tests on both Pythons with ResourceWarnings treated as errors, full validation, wheel import, 52 standalone planning tests and whitespace checks: passed. Publication scans and clean CI remain delivery gates. SQLite bytes are not deterministic artifacts and local state is not a production backend.
