# T06.01 — responsive tokens and semantic shell

Scope: original static HTML/CSS shell, not the grouped reader. The canonical assets are `web/index.html` and `web/styles.css`; no package API, dependency, live source, fetched metadata, client script, remote font, image, policy page or deployment is introduced. The preview explicitly labels itself offline and does not invent news or freshness.

The pre-implementation UX review approved the warm-paper/system-type/teal direction, requiring actual color-usage pair checks and real keyboard/fragment/reflow assertions. The wordmark is noninteractive; landmarks, a first skip link, one h1, labeled sections and focusable fragment destinations establish the semantic shell. Every link has a 44px minimum target and a 3px focus outline. Decorative separators are not treated as readable text or controls.

Executed local validation: **192 tests** passed on Python 3.11 and 3.13 with ResourceWarnings treated as errors, including five new shell tests for structure/heading order, fragment targets, local-only/no-fake-news content, actual-usage token contrast and reflow/focus CSS contracts. Ruff lint and format passed.

The repeatable optional `node tests/render/check_shell_browser.cjs` check used existing external Playwright 1.62.1 and headless Chrome 156.0.8078.76, one isolated context with document JavaScript disabled and reduced motion. It passed at 320×900 and 1280×900: minimum actual text contrast **5.76:1**, all five Tab/Enter links reach the intended focusable targets, focus remains visible and ≥3:1 against adjacent surfaces, targets are ≥44px, and no horizontal overflow or clipping occurs with long synthetic strings or 200% text enlargement. A 320×225 viewport additionally proves 400%-equivalent reflow from 1280×900; it is not a claim to automate browser-chrome zoom. No unexpected requests or page errors occurred. Only the local HTML and CSS were allowed to load.

Final UX review inspected both actual rendered captures and approved the visual/interaction design. Code review reported no critical/high/medium findings. The independent verifier reran `make validate`, both locked supported-version suites, `make test-wheel`, 52 standalone planning tests, whitespace checks and the actual no-JavaScript browser harness: all passed. Wheel imports outside the checkout still pass; no runtime dependency or packaging change is introduced.

Delivery tracks [issue #20](https://github.com/dmoliveira/wrap-brief/issues/20). Publication scans and fresh required CI remain gates before completion. Full story rendering is T06.02; complete-reader assistive-technology/a11y and measured performance budgets remain T06.04. Rollback is a PR revert; there is no external state or migration.
