# Fictional grouping contract corpus — not the real gold gate

This version-1 fixture contains **12 mixed scenarios, 60 Items, 24 labeled cohorts and 120 exhaustive within-scenario pairs**: 48 positive and 72 hard-negative pairs. There are no artificial cross-scenario negatives. All names, events, titles, editorial artifacts and confirmations are hand-authored fiction; no publisher headline/body/permission or real-person record was copied. Reserved URLs and disabled sources are generated by the bounded helper. This does **not** satisfy T05.03.1/.2 or demonstrate real-world precision.

## Labels

The separate fixture-author lane did not inspect grouping code or predicted outputs. Scenario rationales define the fictional event/cohort truth before the first evaluation. One pre-evaluation policy clarification separates rumor and confirmed cohorts even for the same underlying event; grouping must not confer confirmation. Other labels were retained, including paraphrases, localization and deliberate missing-context ambiguity that may expose failures. No label is selected or changed to make the current algorithm pass.

The raw version-1 recipe was validated before its first score with SHA-256 `f2e3ea734a6d36aed33c161f29c06656a890030d906b121d8c1b2a2661b4c296`. This is a reproducibility reference, not proof of rights or label independence. Any later fixture change must explain its labeling reason and publish a new reference; do not silently repair expected labels after seeing failures.

Each scenario has two complete cohorts of sizes three and two. All ten unordered pairs are scored from the **actual full-batch output**, not isolated similarity calls. Similar franchise/game names, editions, versions, repeated outages, source wording, localizations, tracking and corrections do not by themselves establish event identity. The ambiguity case intentionally supplies context the headline heuristic does not possess; a false merge must be reported rather than hidden. These are contract fixtures, not independently adjudicated real-event or human-labeled accuracy evidence.

The strict recipe loader caps the committed JSON at 65,536 bytes, checks exact fields/UTC/model contracts, and constructs complete Source/Item/LeadEvidence records. The product evaluator is pure and accepts already validated scenario records, including separately authorized private evaluations; this helper only accepts its committed synthetic recipe vocabulary. No arbitrary URLs/files are fetched, no current ledger is selected, and no source is approved.

The default developer helper prints aggregate measurements and explicitly marks real-corpus qualification **not assessed**. A valid measurement with a failed numeric target is still an honest measurement, not a passing gold benchmark. Inspect every false merge through the private API; public summaries omit source/item/scenario identities, titles, URLs and paths. Correlated pairs are not independent statistical trials. Do not tune the default 0.85 threshold to this fictional corpus.

To close T05.03, provide a reviewed rights-safe representative **real-event** corpus, independently adjudicated labels and frozen evaluation scope; run ≥100 distinct pairs and report ≥98% observed precision, recall, denominators and false merges. Dataset provenance, rights and label independence are external evidence, not established by a JSON flag/hash or a numeric score. The current delivery issue remains open until that evidence exists.
